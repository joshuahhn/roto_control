# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | `needs-triage` | Maintainer evaluation needed |
| needs-info | `needs-info` | Waiting for information |
| ready-for-agent | `ready-for-agent` | Specified and ready for agent implementation |
| ready-for-human | `ready-for-human` | Requires human implementation |
| wontfix | `wontfix` | Will not be actioned |

Use these labels whenever a skill refers to the corresponding role.
Existing category labels such as `bug` and `enhancement` remain available.
